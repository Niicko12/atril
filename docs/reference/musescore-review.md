# Revisión de MuseScore.com para Atril

Fecha de consulta: 2026-10-24. Revisión de páginas públicas de MuseScore.com y del flujo actual “Buscar o abrir” de Atril.

## Lo que ofrece el catálogo

La portada presenta un catálogo grande con partituras destacadas y en tendencia. La navegación pública incluye **Top Scores**, **New Scores**, **Official Scores**, categorías y News. La página de partituras ofrece filtros por instrumento, dificultad, género, conjunto, tipo (oficial/comunidad) y formato (interactivo/PDF). MuseScore mantiene páginas separadas de nuevas, populares y oficiales; sus cifras cambian, por eso Atril no las copia ni las fija en su interfaz.

## Qué conviene incorporar a Atril

Atril ya permite buscar una canción y enlaza a MuseScore. Para descubrir contenido recién publicado sin mantener un catálogo propio, “Buscar o abrir” ahora ofrece accesos externos a:

- Nuevas partituras.
- Más populares.
- Partituras oficiales.
- Composiciones originales.

Cada enlace abre MuseScore en otra pestaña. El usuario puede volver y abrir en Atril el archivo que haya obtenido allí, si la página ofrece una descarga compatible y las condiciones de la obra lo permiten. También conservamos la entrada de búsqueda por título.

## Límites y derechos

MuseScore distingue obras de la comunidad y partituras oficiales licenciadas de editoriales. Las opciones de ver, reproducir o descargar cambian por obra y por licencia; Atril debe indicar que se revisen esas condiciones. No se descargan, almacenan, incrustan ni vuelven a publicar partituras o imágenes de MuseScore, y no se automatiza el acceso a sus páginas. Así se evita depender de una API no documentada y se respetan los permisos de cada autor/editorial.

Esta integración es un puente de descubrimiento, no una sincronización automática: no hay API, scraping, cuenta de MuseScore ni actualización de catálogo dentro de Atril.

## REA

El usuario pidió revisar el sitio con REA. En esta sesión no aparece conectado el servidor MCP de REA y el comando `rea-agents` no está disponible en la instalación local. Por eso no atribuyo a REA las observaciones anteriores: se basan en las páginas públicas enlazadas abajo. El análisis de ejecución con REA queda pendiente hasta que el MCP de REA esté disponible en Codex.
